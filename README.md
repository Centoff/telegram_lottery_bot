# telegram_lottery_bot
Бот викторины для Telegram с проверкой подписок в ТГ и Макс

📦 Установка зависимостей:
	pip install -r requirements.txt

✅ Что добавлено:
	- Полная структура проекта с разбивкой на файлы
	- WebApp интерфейс с HTML-шаблоном
	- Система наград и уровней
	- Расширенная статистика пользователей
	- Админ-панель с полным функционалом
	- Генерация случайных призов
	- Текстовые статусы подписок
	- Система уровней и наград
	- Система рангов и топ игроков
	- Интеграция с платежами (в теории)
	- Уведомления через Telegram канал
	- Телеграм-бот с голосованием
	- Управление каналами для розыгрышей через админ-панель
	- Управление призами через админ-панель
	- Автоматические розыгрыши со случайным участником по заданной дате и времени
	- Система управления активностью каналов и призов
	- Расширенная админ-панель с новыми функциями
	- Команды /addchannel и /addprize для добавления через сообщения
	- Поддержка автоматических розыгрышей через панель администратора

🚀 Как запустить:
1. Установите зависимости:
	pip install -r requirements.txt
2. Замените YOUR_BOT_TOKEN_HERE в config.py на ваш токен бота
3. Запустите бота:
	python bot.py
4. Запустите WebApp (если нужно):
	python webapp.py
